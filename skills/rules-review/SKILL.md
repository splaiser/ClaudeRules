# Разбор уроков

Цель — одна правка правил за запуск, подтверждённая журналом. Не перестройка правил.

## 1. Сбор
1. Прочитай `.claude/lessons.md` проекта. Нет файла или меньше 3 записей без
   отметки `→` — назови число записей и остановись: данных мало.
2. Прочитай действующие правила: `~/.claude/CLAUDE.md`, CLAUDE.md проекта,
   `.claude/rules/`, скиллы, к которым относятся записи.

## 2. Одна проблема
1. Сгруппируй записи по причине, а не по формулировке. Для каждой группы —
   число записей, даты первой и последней.
2. Возьми одну группу: самую частую; при равенстве — где ошибка дороже
   (переделка, потеря данных, прод). Остальные — списком «на потом», без правок.
3. Правило про это уже есть, а ошибка повторяется после его появления → правь
   формулировку существующего правила, новое не добавляй.

## 3. Уровень правила
- Верно для любого проекта → база. Правка базы действует во всех проектах —
  назови это. Правь в репозитории базы: путь — `readlink ~/.claude/CLAUDE.md`;
  в режиме копии спроси путь к репозиторию. В конце напомни закоммитить.
- Только этот стек или проект → CLAUDE.md проекта или `.claude/rules/<тема>.md`
  с `paths`.
- Нужно для одного вида задач → скилл: он не грузится в каждую сессию.

## 4. Предложение
Покажи:
- группу: N записей, даты, 1–2 цитаты из журнала;
- дифф правки в формате «правило — почему»;
- размер файла до и после; противоречие с другим правилом — обе формулировки;
- чем проверить: пункт из `checks.md` базы или прошлая ситуация из журнала,
  которую повторить в новой сессии.

Записывай только после подтверждения. После записи допиши в конец
использованных строк журнала `→ правило ГГГГ-ММ-ДД`.

## 5. Итог
2–3 строки: что изменено и где, сколько записей закрыто, какие группы остались.

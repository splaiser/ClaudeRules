# Передача состояния

Файл — состояние на сейчас, а не история: перезаписывается целиком, не дописывается.

1. `git check-ignore -q .claude/work/x` вернул ненулевой код → допиши `.claude/work/`
   в `$(git rev-parse --git-path info/exclude)` (локально, в коммиты не попадает).
2. Перезапиши `.claude/work/handoff.md`, до 25 строк:
   ```
   # <цель одной строкой>
   Готово: <что сделано и чем проверено>
   Дальше: <следующие шаги по порядку>
   Файлы: <путь:строки — зачем>  (только те, что понадобятся дальше)
   Решения: <что выбрано и почему; что пробовали и отбросили>
   Открыто: <вопросы к пользователю, известные проблемы>
   ```
   Есть план `.claude/work/<задача>.md` от long-task — сошлись на него, не копируй.
   Не пиши то, что видно из кода или `git log`.
3. Ответ пользователю одной строкой: «Сохранено. Теперь /clear — состояние
   подхватится само (файл свежее 24 ч)». Новая задача вместо этой — файл не нужен,
   достаточно /clear.

# claude-base

Общие правила, скиллы, субагенты и хуки Claude Code для всех проектов.

## Установка и обновление

    git clone <url> ~/claude-base
    bash ~/claude-base/install.sh          # Windows без Developer Mode: COPY=1 bash install.sh

Обновление: `git pull && bash install.sh`. В режиме симлинков правки в репозитории
действуют сразу, установщик нужен только при добавлении новых файлов или хуков.

## Слои

1. `~/.claude/` — эта база (грузится во всех проектах первой).
2. `<проект>/CLAUDE.md` и `<проект>/.claude/` — только команды, стек, особенности
   и явные исключения из базы. Подключить старый или новый проект — `/project-setup`.

## Состав

- `CLAUDE.md` — поведение, подход к задачам, честность, экономия контекста.
- `skills/long-task` — дисциплина многошаговых задач (грузится по требованию).
- `skills/human-text` — вычитка текстов на машинный стиль.
- `skills/project-setup` — подключение проекта к базе (только вручную).
- `agents/test-runner` (Haiku), `agents/reviewer` — вывод и проверки вне основного контекста.
- `hooks/graph-*` — обновление graphify один раз за ход, только после правок.

Правило базы: сюда попадает только то, что верно для любого проекта.
Всё про конкретный стек — в проект.
